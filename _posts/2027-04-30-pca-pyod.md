## PCA
- some math about PCA in general
- PCA with time series data (anomaly detection)

PCA (Principle Component Analysis) is a common used tool for dimensionaility reduction. [explenation about this].
When using it as a classifier for outlier detection like described by Shyu et al. you adapt several steps <d-cite key="shyuPrincipalComponentbasedAnomaly2005"></d-cite>. For every varible $k$ for all datapoints the mean, variance and standard diviation is  estimated. With these we now can standardise all values. This is necessary because we can have very different scales for the values.

$$z_k = \frac{x_k - \bar{x}_k}{\sqrt{s_{kk}}}$$

The standardisation in the paper is described with ddof=1. This estimator is more robust then the one with ddof=0, as we don't actually know the real standard diviation.

$$s_{kk} = \frac{1}{n-1} \sum_{j=1}^{n} \left( x_{jk} - \bar{x}_k \right)^2, \qquad \bar{x}_k = \frac{1}{n} \sum_{j=1}^{n} x_{jk}$$

To make the PCC more robust the $\gamma \cdot n$ values are removed, as they might contain extrem values. In the paper they used $\gamma=0.005$ for their experiments. Mean and covariance are estimated again.

Eigenvalues and eigenvectors are calculated via eigenvalue decomposition from the covariance matrix $R$. This is the $p \times p$-matrix of the standardised values $\mathbf{z}$. The result from the eigenvalue decomposition are $p$ pairs of the eigenvalue and unit eigenvector $(\lambda_i, \mathbf{e}_i)$.

Important for anomlie detection is the principal component score. This is calculated by projecting each datapoint (standardised) onto the principal componentents by

$$y_i = \mathbf{e}_i' \mathbf{z} = e_{i1} z_1 + e_{i2} z_2 + \dots + e_{ip} z_p$$

In the paper the major and the minor components are used to detect the anomalies. The major components are those, that explain more than 50% of the total variance. This is used to detect anomalies, which are highly correlated but with an extrenm value.

$$\sum_{i=1}^{q} \frac{y_i^2}{\lambda_i}$$

The minor component on the other hand is used to find anomolies which are not correlated. These are selected by $\lambda_i < 0.20$ (so basically linear dependencies):

$$\sum_{i=p-r+1}^{p} \frac{y_i^2}{\lambda_i}$$

To detect only anomalies an outlier threshold needs to be defined. A value is defined as anomalie if Major > $c_1$ OR Minor > $c_2$. The paper defines $\alpha = \alpha_1 + \alpha_2 - \alpha_1\alpha_2$. The threshold should be selected based on empirical-distribution. These threshold tells us the quantil for finding $c_1$ and $c_2$.

## Appendix 1

Norm as a dot product

$$\lVert z - s_i e_i \rVert^2 = (z - s_i e_i)'(z - s_i e_i)$$

Expand it, and as the dot product is symmetric, we can combine the two middle terms

$$(z - s_i e_i)'(z - s_i e_i) = z'z \;-\; s_i\, z'e_i \;-\; s_i\, e_i'z \;+\; s_i^2\, e_i'e_i = z'z \;-\; 2\, s_i\, e_i'z \;+\; s_i^2\, e_i'e_i$$

Now we substitute

| Term | Value | Reason |
|---|---|---|
| $z'z$ | $\lVert z \rVert^2$ | definition of the norm |
| $e_i'z$ | $y_i$ | Shyu et al., Eq. (4): $y_i = e_i'z$ |
| $s_i^2$ | $1$ | $s_i \in \{-1, +1\}$ |
| $e_i'e_i$ | $1$ | eigenvectors have unit length (`components_` is orthonormal) |

This gives:

$$\lVert z - s_i e_i \rVert^2 = \lVert z \rVert^2 - 2\,s_i\,y_i + 1$$

Take the square root

$$\lVert z - s_i e_i \rVert = \sqrt{\lVert z \rVert^2 - 2\,s_i\,y_i + 1}$$
